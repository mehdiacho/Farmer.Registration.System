# History

Earlier versions of this project, kept as they were. The app at the top of the repo replaces them; nothing in
here is built or run by Gradle.

| Folder | What it is | Status |
|---|---|---|
| [`swing-2022/`](swing-2022) | The original 2022 Java Swing + MySQL assignment. | Compiles on JDK 17+ after the May 2023 fix. Needs a local MySQL server with `Assignment/farmersbw.sql` imported. |
| [`android-2022/`](android-2022) | A start on an Android version: one dashboard screen. Moved here from the separate `mehdiacho/FarmersBW` repository, keeping its commits. | Source files only (no Gradle build files were ever committed). The dashboard layout came from the [BIUST Hackfest 2022](https://github.com/mehdiacho/BIUST.Hackfest.2022) golf tournament app. |

The tag `original-2023` points at the repository as it was before the 2026 rebuild.

The people in `swing-2022/Assignment/farmersbw.sql` are fictional. In 2026 the git history was rewritten to
put them in place of the real names, contact details and passwords that were in the original dump.
